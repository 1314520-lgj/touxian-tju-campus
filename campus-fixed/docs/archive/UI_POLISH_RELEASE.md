# 偷闲·天大版 1.4 页面美化版

本版把已有学生信息工作台整理为清爽的蓝白界面。主要目的仍是减少查找和阅读通知的时间：完整标题、清晰截止时间、可读行动说明与原文依据优先。基于 1.3 授权供稿与正文增强版，服务端、接口、数据结构及 Google Cloud 部署方式沿用原版。

## 借鉴来源与取舍

查阅时间：2026-10-08。以下为设计参考，校园页面使用原有 React、CSS、Lucide 独立实现。

| 原始项目 | 借鉴内容 | 在校园页面中的实现 |
| --- | --- | --- |
| [DeepSeek Harness 官方样式规范](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/web-styling.md) | 统一语义颜色、字号配行高、可见键盘焦点、减少动态效果偏好 | 单一语义配色表、统一按钮/卡片/表单、高对比焦点与 reduced-motion |
| [DeepSeek Harness 官方布局说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-layout/README.md) | 保护主内容空间，窄屏折叠侧栏 | 安静的窄侧栏、移动导航抽屉、主要内容自适应 |
| [oil-oil/dsh-theme 社区主题项目](https://github.com/oil-oil/dsh-theme) | 调色与文字层级统一管理 | 蓝白校园视觉，中文系统字体，明确正文/辅助说明层级 |

保留偷闲与天津大学产品定位。没有引入 DeepSeek 品牌图案、主题插件、新模型接口、额外字体下载或组件框架。社区项目作为参考，不代表 DeepSeek 官方推荐。参考项目里的多主题编辑器不属于本版需求。

## 已实现的变化

- 配色集中在 `src/campus/campus.css` 的语义变量中；导航、事项、搜索、来源、设置和管理页使用同一套视觉规则。
- 事项卡标题为 18px，截止与匹配说明为至少 13px，行动说明为 14px；完整标题和行动说明允许自然换行。
- 卡片区分分类、标题、截止、行动与次要操作；保留待核实、合成演示数据、订阅供稿未直接核验等真实状态说明。
- 桌面首页采用三个流程说明；手机收起辅助流程说明，优先让学生看到通知。
- 手机导航提供可见关闭按钮、自身滚动和安全区域留白；转到桌面宽度时自动收起抽屉。
- 弹窗标题与关闭键保持可见，内容内部滚动，使用动态视口高度适配短屏；手机表单字号 16px。
- 增加跳至主内容链接、当前导航标识、事项筛选状态；保留焦点循环、Escape 关闭、焦点恢复与减少动态效果偏好。
- 菜单和弹窗共享按持有者释放的滚动锁，修复叠加窗口乱序关闭后无法滚动的问题。

## 分工与验收

界面负责人修改 App.jsx 和 campus.css；独立 AI 审阅布局与无障碍并编写 `src/campus/tests/ui-polish.e2e.mjs`；最后串行合并、编译和真实浏览器回归。没有两个 AI 同时修改同一产品文件。

实际运行结果以发行包中的 `本版验收记录/final-verification.json` 及各 browser report 为准。新增脚本连接真实本地 HTTP 服务，不拦截接口；覆盖 1440/768/390/320px、搜索、来源、手机导航、短屏表单、正文对比度、键盘焦点、减少动态效果和叠加窗口滚动锁。所有通知均为明确标注的合成数据。

本版沿用 1.3 服务端，历史服务端验收单独放在 `baseline-1.3-verification.json`；历史结果不能视作本版重新执行。截图包含演示提示，不是真实学校采集证明。

## 运行与部署

发行包已有构建好的网页，按 `README-CAMPUS.md` 运行本地演示即可查看。Google Cloud 的固定 `run.app` 网址配置仍见 `deploy/cloudrun/DEPLOY.md`，需要用户之后创建自己的项目。本轮未创建云项目或公网服务。

本版不更改数据库结构。已有安装升级前先停止服务并备份数据及配置，再替换应用与网页构建文件。回退使用原 1.3 应用与其对应构建文件。

真实学校网络采集、公众号授权、SMTP/GCS、校园网络访问 run.app 和学生节省时间仍需实际环境验收。此次页面美化没有消除这些上线前的验证缺口。
