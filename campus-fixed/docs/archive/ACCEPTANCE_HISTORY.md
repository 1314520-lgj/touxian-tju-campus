## 1.6.0 变化可见性 · 中文检索索引 · 无障碍自动化（2026-10-09）

| 验证 | 本轮实际结果 |
|---|---|
| 完整校园后端 | **368 passed / 8 skipped / 0 failed**，另 91 个子场景通过；真实 SQLite、HTTP、事务与队列，网络与 SMTP 为明确标记的合成替身 |
| API 契约 | **56/56** 成功响应逐条核对通过；新增 `GET /events/{event_id}/changes` |
| 新增用例 | 后端 23 条：`test_event_changes.py` 10 条、`test_search_index.py` 13 条 |
| 中文检索索引 | 开启索引与关闭索引的命中集合逐条一致；过期凭据下仍全量扫描命中新内容；非 SQLite / 无 FTS5 时自动回退 |
| 无障碍扫描 | axe-core 4.10.2，**17 个场景 0 违规**；仅渐变背景对比度按设计 defer 给像素级检查 |
| 前端单元 | 22 passed（boundaries 15 / feedView 5 / sourceSelection 2） |
| 真实后端浏览器 | `browser.e2e.mjs` 11 项（含真实中文 OCR）、`ui-polish.e2e.mjs` 20 项通过；无 route 拦截，无浏览器异常与 HTTP 5xx |
| 生产网页构建 | Vite build 通过，`dist/` 随包交付 |

本轮三处增量改动：

1. **变化摘要接入**：`parse_document` 在写库前完成一次比对，同一个 `change` 对象同时供公开接口 `GET /events/{event_id}/changes`、事项详情"变化记录"页签与管理台解析记录使用。首次采集不报变化，未被当前版本采纳的采集不出现，撤回后返回 404。
2. **中文检索索引**：新增同库 FTS5 表 `campus_segment_fts`，一元 + 二元切分。因为任意长度 ≥2 的子串都包含自身全部二元组，"对词的 token 取 AND"不会漏掉子串命中——索引只能缩小工作量、不能改变结果。纯汉字查询才走索引；ASCII 词、过期凭据、非 SQLite 后端一律回退全量扫描。近义词表只在字面命中不足 2 个事项时启用，且扩展命中永远排在字面命中之后。
3. **无障碍自动化**：新增 `a11y.e2e.mjs`，注入 `vendor/axe.min.js`（axe-core 4.10.2，MPL-2.0）就地执行。`serious`/`critical` 违规与 ARIA 规则的 `incomplete` 均判失败；引擎文件缺失直接中止，避免"零违规 = 零检查"。据此修复弹窗重复 banner 地标、侧边栏 `aside role="dialog"` 非法角色、四处 `h1 → h3` 跳级与两处 `generic` 角色上的 `aria-label`。

**没有引入新的 Python 或 npm 运行时依赖**：本地索引使用标准库 `sqlite3` 的 FTS5；axe-core 仅作为测试资产随包存放，不在运行时加载。

边界：变化摘要只指出"哪一段变了"，不判断重要性；本地索引只服务当前版本，勾选历史版本仍走全量扫描；近义词表人工维护、不做主题联想；无障碍扫描针对显式合成演示数据，真实接入来源后的长正文与附件需另跑一次。

- 当前 DNS 将天大域名映射到保留 fake-IP，采集安全拒绝。需在正常公网 DNS 环境实际抓取并核对通知、附件和日期抽取准确率。
