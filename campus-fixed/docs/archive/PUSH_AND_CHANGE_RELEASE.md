# 1.5 能力记录：变化检测、相对时间与推送

本文件保留 1.5 的能力背景。当前产品为 **1.7.0**、公共契约为 **1.5.0**，现行配置和边界以 [UPGRADE_1_7.md](UPGRADE_1_7.md) 及 [README](README.md) 为准。旧版全局推送与 Apprise 传输已被个人安全网关方案替代，旧说明不能作为当前部署或送达证明。

## 快照变化检测

`sources.persist` 使用整篇哈希复用完全相同的原文快照。`change_detect.py` 对比同一文档的文本块，记录新增、删除、改写和未变化段数；全角/半角与空白差异不计为修改。摘要引用留存文本，并标记时间或期限可能变化、内容增删、措辞调整；报告有段数上限，超出时标记 `truncated`。

解析路径把每次采集相对上次的摘要写入文档 `change_summaries`；首次采集没有变化记录。1.5 当时只保存摘要，1.6 接入 API 与界面，1.7 补齐历次已公开版本采纳的公开快照历史。没有被公开版本采纳的中间稿不对学生展示；事项撤回后变化接口返回 404。需要跨过未公开的中间稿时，公开摘要只对比前后已采纳原文，不引用中间稿内容。

## 中文相对时间补充

`zh_time.py` 仅在既有日期解析器没有给出结果时补充相对表达，不能覆盖已经识别的字面日期。缺少发布锚点时不推算日期；重复时间或缺少学期起点时保留人工核对提示。

| 规则 | 表达与边界 |
| --- | --- |
| 下下周 | 依据明确发布锚点推算 |
| 若干天或一周后 | 依据锚点换算日期 |
| 若干工作日内 | 近似折算，并进入人工核对；不代表真实节假日工作历 |
| 月末、年末、季度末 | 依据锚点确定边界，仍需核对原文 |
| 每周、每月 | 标记重复表达，不生成没有依据的具体期限 |
| 学期第几周 | 缺少学期起始日时不猜日期 |

补充日期会触发 `relative_time_requires_review` 等候选警告，投影仍遵循冻结的 Deadline 契约。学校只给日期时保持日期精度，不补造具体截止时刻。

## 推送：1.7 已替代旧实现

1.5 的全局 `CAMPUS_PUSH_ENDPOINTS` 配合 Apprise/普通 webhook 的方案已经停用。当前服务忽略该全局变量，`requirements-push.txt` 无额外依赖，应用不通过默认 urllib 或 Apprise 发送个人事项。

服务器使用 `CAMPUS_PUSH_USER_ENDPOINTS` 保存“登录用户 UUID → 本人独享公网 HTTPS 网关列表”的 JSON。示例仅表示语法，UUID 和地址都须替换：

```json
{"11111111-1111-4111-8111-111111111111":["https://push.example.invalid/users/student-a"]}
```

- UUID 使用登录后 `GET /api/v1/me` 的 `user.id`；目标须经用户确认实际收件人仅为本人。映射与地址密钥仅保留服务器，API 与 worker 配置保持一致，修改后重启。
- 每人最多 4 个公网 HTTPS 443 端点。不同用户共享同一规范化目标时双方被拒绝；同一人的等价重复目标去重。
- 目标网关须接受 JSON `title`、`body` 和 `Idempotency-Key`。本版没有承诺任意企业微信、钉钉、飞书 webhook 可以直接接收该结构。
- 本人 `GET /api/v1/me/push-status` 需要登录，仅返回 `available` 与 `reason`。`ready` 是绑定配置状态，不能替代真实送达验收；其余状态为 `unconfigured`、`invalid_configuration`、`shared_destination`。
- 未安全绑定时界面提示不可用，偏好写入选择 `push` 返回 409 `PUSH_NOT_READY`。旧排队任务无有效本人绑定时失败，不转向全局地址。
- 每次发送前核验所有 DNS 地址，只连接固定的公网 IP，保留 TLS 主机名校验，拒绝私网、元数据、混合 DNS 与重定向。载荷最多 16 KiB，传输有超时限制；系统 DNS 解析仍由操作系统管理。
- 发送前确定未外发时记为 `failed`；发送后结果不明或只有部分目标接受记为 `unknown`，不自动盲目重发。`push` 与邮件都遵守免打扰时间。

## 契约与验证

公共契约现为 **1.5.0**，接口与字段见 [openapi.v1.json](campus-contracts/openapi.v1.json)。变化摘要、质量提示和本人推送状态按当前契约验证，不能用 1.5 的旧操作数或旧测试统计替代当前结果。

验证范围包含文本变化、相对时间人工核对、两名学生私密提醒及简报隔离、共享目标拒绝、无绑定拒绝、会话/CSRF、公网 DNS/TLS 校验、重定向拒绝和重复发送认领。具体测试与跳过项 **以最终验收报告为准**。

本轮网络、邮件和推送使用合成资料与模拟传输，没有向真实个人网关外发。真实校园来源、公众号授权、SMTP 与实际收件人需在目标部署环境逐项验收。
