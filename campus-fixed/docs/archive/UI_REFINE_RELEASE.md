# 界面品位版：纸与墨

只改 `src/campus/campus.css`；组件、逻辑、class 名、响应式断点均未变。`dist/` 与 `web/` 仍逐字节一致。

## 设计语言
- 暖纸色底、北洋墨蓝承担结构；朱砂红只用于品牌印章和与时间有关的信息（截止图标、临近截止标签、需行动卡片顶部小红线、原文依据的左侧线）。
- 页面标题、大数字、品牌名使用系统宋体（`--serif`），不下载字体；Windows 无思源宋体时回退到 SimSun。卡片标题与正文保持黑体。
- 细线分隔取代阴影与彩色底块；圆角收敛（卡片 10px，按钮 8px）。
- 所有颜色集中为 `:root` 语义变量，包括警示、错误、成功、临近截止、演示横幅、骨架屏。

## 深色“墨夜”
跟随系统 `prefers-color-scheme: dark`。文字用的强调色提亮，按钮保持深色填充（`--accent` 与 `--accent-fill` 分开），朱砂在深色下提亮为 `--seal-text`。

## 验证（本环境）
- 前端单元测试 33 通过。
- Chromium 加载构建产物 + 模拟接口，桌面 1440 与手机 390，首页/今天/搜索/来源/详情/设置，浅色与深色：无页面报错；逐文本节点计算对比度（正文 4.5、大字 3），浅色 0 项、深色 0 项不达标。
- 样式压缩用 esbuild（目标与 vite 默认 `modules` 一致）；先对 1.9 原样式复现，输出与随包 `campus-ZtFcd0uZ.css` 逐字节相同，再用于新样式。
