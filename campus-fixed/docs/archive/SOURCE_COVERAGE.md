## 公众号及其他缺口

教务处官网显示“天津大学教务处”公众号入口，就业官网显示“天大就业”等公众号入口。本目录只保存学校公开网页及明确的公众号原文链接；**尚未取得公众号供稿授权或建立已验证的授权订阅**。站外正文失败时应显示采集错误或待补充，不推断不可见正文中的日期、材料或资格。

现有公众号适配接口可对接运营者已获授权的订阅服务。后续增加公众号时，需要核对帐号身份、授权方式、更新频率和失效提示。学生可先请求添加来源，或私下导入自己取得的文字、链接和截图；个人导入内容按私有数据处理。

本次未确认稳定公开的本科资助专用通知栏目，不能以研究生奖助栏目代替。就业网站“招聘简章”入口曾返回登录提示，也没有列为公开可抓来源。校园认证系统、班级群和未授权公众号不在自动覆盖承诺内。

第 8 轮（2026-10-13）运营方提供了 11 个官网首页与 16 个公众号文章链接。逐条服务端实测结论：`i.tju.edu.cn` 与 `zzzx.tju.edu.cn` 抓取失败（域名用途待运营方确认）；`www.tju.edu.cn`（官网首页，无独立通知列表）、`lib.tju.edu.cn`（JS 单页）、`www.twt.edu.cn`（学生工作室站）不构成可用通知列表，均未注册；`https://mp.weixin.qq.com/s/...` 16 条全部返回微信「参数错误」，不是真实文章。证据见 `verification/operator-sources-2026-10-13.json`。

## 配置与验收规则

- 旧的教务处、智能与计算学部、新闻网 3 个来源 ID 与 URL 保持不变，已有订阅可继续使用。新增 ID 为 `uuid5(NAMESPACE_URL, 'tju-campus-source:' + origin_url)`，不因展示名称修改而改变。
- 每个详情链接规则限定对应学校主机，避免把其他域名上长得相似的路径纳入该来源。教务栏目额外识别明确的 `https://mp.weixin.qq.com/s` 外链；这只表示发现链接，不代表成功读取。
- 新目录必须同时加入服务端可信种子身份表，普通配置或学生提交的 URL 不能自行获得“官方已核验”身份。配置不写健康状态或最近成功时间。
- 核验材料是本次打开的官方栏目页面，不是完整历史镜像。目录扩展不增加采集分页承诺，历史补采范围按实际采集配置与积压状态显示。
- 上线验收须使用应用自己的安全采集器检查 DNS、重定向、正文与附件，并由实际采集记录证明成功。若部署环境的 DNS 返回保留、私有或混合地址，应报告受阻，保留安全限制。

本机已对 15 个栏目执行实际 `SafeFetcher` 探测，全部返回 `unsafe_address`：当前环境 DNS 将相关主机映射到非公网地址。诊断保存在交付包的 `SOURCE_FETCH_PROBE.json`。**本机没有成功完成这些来源的正文实采**，不调整校验来掩盖失败；部署到新环境后需要重新探测，可信种子的初始状态仍为 `never_checked`。

`server/campus/tests/test_source_catalog.py` 是离线配置回归：验证 ID 兼容性、官方主机边界和真实网站出现的就业路径形态。测试链接的文章编号只作路径形态夹具；离线通过不证明对应文章存在，也不证明网络采集成功。

## 真实短摘录语料

`fixtures/notice-corpus/official-notices.json` 保存 20 个不同官方页面的短摘录及人工标注，每页摘录最多 25 个字符。每条附原文 URL，标题是人工简写标签；只保存可核实的发布日期，不用招生届别推算缺失年份。已知发布日期以北京时间零点作为日期锚点，精度为日，不代表网页实际发布时刻。表格竖线可能来自网页工具的文本渲染。

语料覆盖绝对及省略年份日期、活动区间、相对工作日、材料豁免、条件资格、提前改期和面向雇主的公告。所有短摘录都需要结合原文复核，人工标注不能替代完整公告审查。它是针对已发现缺陷的回归样本，**不能报告为全站召回率、完整公告准确率或学生节省时间的实验结果**。日期与材料字段评估应单独报告命中、遗漏及未知，不用“全部需复核”计算看似漂亮的准确率。

下一次扩大覆盖时，先补本科资助和学生高频实际来源，再建立有授权的公众号接入。学生试用需要真实使用记录及对照测量，不能以来源数量或测试通过数代替。
