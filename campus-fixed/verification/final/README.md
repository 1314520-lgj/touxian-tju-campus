## 四、本轮的真实账（交付说明用，不列任务名充数）

- **学生可见增量（实测）**：`data-operator` 上跑一次完整日常更新 **公开列表 100 → 100，新增可见 0 条**；
  全新安装（冷启动）首天可见 **8 条**。t26 注册 4 个学院栏目后，**副本上第一次运行 +4 条**（含历史积压）。
