# 偷闲·天大版 · 班级使用说明

给班长、学委、团支书等班级干部：用它快速看清「最近有哪些事、什么时候截止、要交什么、去哪里办」，再转告同学。

> 先说明：当前随包数据是 **2026-10-09 的历史样本**，很多事项已过期，只能用来熟悉界面。要拿它办真事，需要运营者接入并核验实时来源。办理前一律点「查看原文」，以学校原通知为准。

## 1. 打开

由负责部署的同学启动后，在浏览器打开他给的地址（本机演示是 `http://127.0.0.1:8000`）。**不登录也能看公开事项**；登录后可以收藏、标记状态、整理群通知。

## 2. 每天怎么看

| 想知道 | 去哪里看 |
|---|---|
| 最近有什么事 | 「今天」：最近公开事项，按紧急程度排序 |
| 评奖评优、竞赛、活动、招聘 | 「机会」：按类型筛选 |
| 某件事的具体要求 | 「找信息」：输入关键词（如“奖学金 材料”），结果显示原文片段 |
| 自己要做的事 | 「我的事项」（需登录） |
| 信息从哪来的 | 「信息来源」 |

## 3. 打开一个事项后看什么

- **截止时间**：报名/提交截止，以及活动时间。带「已截止」标记的事项已经过期，默认折叠在「历史通知」里。
- **所需材料**：要准备或上交的东西，转告同学时直接照抄。
- **办理入口**：报名链接或办理网址，点进去就是办理地方。
- **原文依据**：每条信息都能回到学校原通知，对不上就以原文为准。
- **「内容有更新」**：通知改过版本，要重新核对。

## 4. 给全班通知的建议流程

1. 在「今天」/「机会」里挑出与本班相关、**未截止**的事项；
2. 记下：做什么、截止日期、材料、办理入口；
3. 打开原文核对一遍，再在班群转发（附原文链接）；
4. 登录后可「收藏」或设为待办，过后回来看有没有更新。

群里别人转来的通知，可以登录后点「添加个人事项」，用本地文字整理，内容只保存在自己账号下，不会公开。

## 5. 常见问题

- **登录收不到邮件？** 本地演示模式验证码直接显示在登录页；正式部署需要运营者配置邮件服务。
- **看不到新通知？** 来源默认停用，数据不会自动更新，需要运营者启用采集。
- **信息和原通知不一致？** 以原通知为准，并告诉运营者。
